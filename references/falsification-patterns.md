# 证伪条件怎么写

> **何时加载**：要素④卡在「什么证据会推翻」写不出来时。
> 写不出证伪条件，说明你手里的是立场不是判断——这一栏不允许留空或填占位。

## 一、三条硬要求

1. **可观测**：写「看到什么就算推翻」，不写「如果情况变了」。
2. **可判定**：别人照着这句话能得出同样的结论，不需要你的临场解释。
3. **有代价**：条件真实可能成立——如果它永远不可能发生，等于没写。

## 二、三种基础写法

| 写法 | 句式 | 适用 |
|---|---|---|
| **阈值型** | 若 {可观测指标} 达到 {N}，则本透镜不再适用 | 有量化读数的判断 |
| **对照型** | 去掉 {被判断的因素} 后结果无变化，则它不构成原因 | 归因类判断 |
| **前提型** | 若 {前提} 不成立，则整条结论不适用 | 依赖隐含前提的判断 |

**反例**：「如果情况变化则需重新评估」——不可观测、不可判定、无代价，三种要求全不满足。

## 三、12 条反例模式（写不出来时逐条套）

| # | 模式 | 句式 |
|---|---|---|
| 1 | 阈值 | 若 {指标} 达到 {N}，本判断失效 |
| 2 | 对照 | 去掉该因素后结果无差异 → 它不是原因 |
| 3 | 单例 | 出现一个反例即推翻这个全称断言 |
| 4 | 时限 | 到 {绝对日期} 未出现 {预期} → 判失效 |
| 5 | 前提 | 前提 {P} 不成立 → 结论不适用 |
| 6 | 范围 | 对象不属于 {类别} → 不适用 |
| 7 | 量级 | 差异小于 {量级} → 差异无实际意义 |
| 8 | 双重失效 | 两道防线同时失效才成立，只失效一道不成立 |
| 9 | 指标失真 | 该指标成为目标后不再是好指标（Goodhart） |
| 10 | 静默 | 没有报警 ≠ 没有问题，须受控负向用例验证 |
| 11 | 归因 | 无法回指到锚点 → 结论降为「未回指」 |
| 12 | 覆盖 | 覆盖面未经机器证明 → PASS 不等于无遗漏 |

## 四、自检（每条证伪条件过一遍）

- [ ] 能不能指出**具体观察到什么**就算推翻？
- [ ] 换成另一个人，会不会得出同样的判定？
- [ ] 这个条件在半年内**真的可能发生**吗？
- [ ] 有没有使用「情况变化」「视情况而定」这类不可判定的措辞？

任一答案为否 → 重写，不许交稿。
