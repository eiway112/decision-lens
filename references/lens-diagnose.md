# 透镜卷 · diagnose（归因 / 边界与停止）· 12 张

> **何时加载**：S1 分类后，决策类型维度命中「归因 / 边界」时加载本卷。
> **字段纪律**：同 decide 卷——`改变了哪个决策` 必须含转折；`什么证据会推翻` 与 `何时不该用` 不得留空。

### P-01 · 交付物本身是判据时，禁「先建后拆」（源自 V15）

**主张**：治具 / 门禁 / lint / 规范类产物必须先小范围实证再上线，不能先建整体再拆。

**怎么用**
1. 先识别产物性质：它是**判据**还是**被判对象**。
2. 是判据 → 小范围实证先行，不许宽构建。
3. 是被判对象 → 可用 D-15（宽构建窄交付）。

**改变了哪个决策**：原打算「先把整套门禁建起来再逐步调」→ 改为「尺子本身先小范围校准，再谈铺开」。

**什么证据会推翻**：若该产物经证明不是判据（不参与任何放行判定），则本透镜不适用。

**何时不该用**：产物是被判对象而非判据时——此时用 D-15。

**互斥组**：边界与停止（M-09 / P-01 / D-15 / D-16），同组最多选 1

### P-02 · 编译期错误是本金加复利（源自 K02）

**主张**：查询期错误随查询消散；编译期错误落盘后会被后续推理反复引用成证据，开始自我繁殖。

**怎么用**
1. 区分「源事实」与「编译叙述」——两者混写即是污染源。
2. 结论必须回指原始采集文件，不得引用中间产物。
3. 禁止两条编译产物互为证据。

**改变了哪个决策**：原打算「从上次提炼的卡片里再提炼一层」→ 改为「回原始文件重取，中间产物不作证据」。

**什么证据会推翻**：若编译产物经证明每次都回源复核（无引用闭环），复利效应不成立。

**何时不该用**：存在强制回源校验机制时。

**互斥组**：无
**来源**：[自撰]

### P-03 · 留痕与生效是两个权限（源自 K05）

**主张**：写进档案不等于真正生效；判断一条规则是否起作用，只看它有没有进注入面。

**怎么用**
1. 失效时先查：它进注入面了吗。
2. 查法：造一个只有该规则能拦住的输入，看是否被拦。
3. 把归因从「模型没遵守」搬到「没进注入面」。

**改变了哪个决策**：原打算「再写一遍更强的措辞要求遵守」→ 改为「先查它有没有真的被送到模型眼前」。

**什么证据会推翻**：若规则确已进入注入面仍无效，则问题在措辞或模型能力，本透镜已耗尽。

**何时不该用**：注入面不可观测、无法验证时——先解决可观测性。

**互斥组**：归因定位（P-03 / P-11 / P-07 / P-06），同组最多选 1
**来源**：[自撰]

### P-04 · 提炼与边界优于平铺，隔离优于压缩（源自 K06）

**主张**：原始材料须提炼成带适用 / 不适用边界的规则；噪声不进主上下文，优于进来再压缩。

**怎么用**
1. 个案集合必须显式写边界，否则不算规则。
2. 中间结果用子代理隔离，别塞回主上下文。
3. 压缩要晚而批量，不要逐条压。

**改变了哪个决策**：原打算「把这批案例都塞进上下文让它自己总结」→ 改为「先提炼成带边界的几条规则，案例隔离」。

**什么证据会推翻**：若提炼后的规则在新案例上漏判多于直接用案例，则提炼损失大于收益。

**何时不该用**：案例数极少（≤3）且边界尚未成形时——此时提炼会过早收敛。

**互斥组**：无
**来源**：[自撰]

### P-05 · 小世界 / 大世界：该不该建记忆机制（源自 K11）

**主张**：通用且稳定的知识属小世界，交给基座一次训练；具体到某用户或组织且常变的属大世界，才须部署侧持续积累。

**怎么用**
1. 建记忆机制前先判：这类知识通用吗？稳定吗？
2. 两者皆否 → 才值得建。
3. 否则交给模型，别自己攒。

**改变了哪个决策**：原打算「建个记忆库把所有知识存起来」→ 改为「先判大小世界，小世界不建」。

**什么证据会推翻**：若基座模型在所谓「小世界」知识上经实测频繁出错，则划分需重估。

**何时不该用**：知识既通用又稳定时（此时本透镜直接给出「不建」，无需展开）。

**互斥组**：无
**来源**：[自撰]

### P-06 · 「知道但没做到」的差距才是优化方向（源自 H10）

**主张**：理论储备远超落地程度时，真正的优化对象是落地率，不是继续补理论。

**怎么用**
1. 统计「已提炼 / 已落地」比例，把差距摆上台面。
2. 比例低 → 优化对象是落地机制，不是再读一篇。
3. 定期复审，不藏起来。

**改变了哪个决策**：原打算「再补一批相关知识」→ 改为「先把已提炼的两条装上，落地率就是治理项」。

**什么证据会推翻**：若落地率已接近 100% 而效果仍不达标，则缺的确实是理论，本透镜不适用。

**何时不该用**：落地率已高、问题出在知识质量时。

**互斥组**：归因定位（P-03 / P-11 / P-07 / P-06），同组最多选 1
**来源**：[自撰]

### P-07 · 价值在鞍具，不在模型（源自 A01）

**主张**：稳定交付的 AI 能力，价值杠杆在模型外围的鞍具——注入什么上下文、约束什么范围、如何校验、失败如何降级。

**怎么用**
1. 优化顺序：先调上下文与约束 → 再调校验与降级 → 最后才考虑换模型。
2. 每一步单独测，不一次改两处。
3. 换了模型仍不稳，回到第一步。

**改变了哪个决策**：原打算「效果不好，换个更强的模型」→ 改为「先把上下文和约束调对，换模型是最后一步」。

**什么证据会推翻**：若在同一鞍具下换模型带来显著且稳定的提升，则杠杆确在模型侧。

**何时不该用**：上下文与约束已调到极限、确认瓶颈在模型能力时。

**互斥组**：归因定位（P-03 / P-11 / P-07 / P-06），同组最多选 1
**来源**：[自撰]

### P-08 · 结构一致性可外包，内容质量不能（源自 S04）

**主张**：机检只能保证结构一致；内容质量必须由人或独立评估承担。两者责任不可混。

**怎么用**
1. 机检覆盖结构（字段齐全、编号连续、引用存在）。
2. 内容走独立评审或人工抽检。
3. 各自留证，互不冒充。

**改变了哪个决策**：原打算「加个检查脚本，内容质量也一起保证了」→ 改为「脚本只守结构，内容另走评审」。

**什么证据会推翻**：若内容质量经证明可被机器稳定判定（如有 ground truth 的评分集），边界可前移。

**何时不该用**：产出本身有可机验的正确性判据时（此时可外包）。

**互斥组**：无
**来源**：[自撰]

### P-09 · 待裁定事项须带绝对到期日（源自 G04）

**主张**：待裁定项必须写明绝对到期日；默认动作为「维持现状并告警」，绝不默认放行。

**怎么用**
1. 每条待裁定项写明绝对日期（不是「下周」）。
2. 到期默认维持现状 + 告警，不自动放行。
3. 无到期日的待办一律视为未决。

**改变了哪个决策**：原打算「这条先挂着，以后再说」→ 改为「写明到期日，到期默认不放行」。

**什么证据会推翻**：若某类待裁定项经证明拖延时无风险（如纯偏好），则到期机制是负担。

**何时不该用**：裁定本身无需外部输入、可立即决断时。

**互斥组**：衰减与失效（D-17 / P-09 / M-10），同组最多选 1
**来源**：[自撰]

### P-10 · 判据指向唯一机器源，复述即漂移（源自 G08）

**主张**：规范只引用不复制数值；文档里的「当前账」只写快照与时点，「当前」二字留给机器。

**怎么用**
1. 数值类判据一律指向唯一机器源。
2. 文档引用时给读取方式，不给数值。
3. 发现手抄数值 → 判为漂移，改回引用。

**改变了哪个决策**：原打算「在规范里写明当前有 42 条透镜」→ 改为「写『见脚本 --check-catalog 读数』」。

**什么证据会推翻**：若机器源本身不可读（外部依赖失效），则只能快照 + 标注时点。

**何时不该用**：数值需人工作为契约固定（如对外承诺的版本号）时——此时快照是对的。

**互斥组**：数字口径（M-06 / M-07 / P-10），同组最多选 1
**来源**：[自撰]

### P-11 · 先分工具缺陷与来源缺陷（源自 G11）

**主张**：检索零命中而下否定结论前，先排除转换通道把目标吞掉的可能；否定断言须写明「在哪个介质上零命中」。

**怎么用**
1. 零命中先做阳性对照：造一个已知应命中的样本，确认方法有效。
2. 阳性对照通过 → 才能下否定结论。
3. 否定结论写明介质与通道。

**改变了哪个决策**：原打算「查了没找到，说明没有」→ 改为「先造阳性对照证明查法有效，再下结论」。

**什么证据会推翻**：若阳性对照本身也零命中，问题在工具/通道，不在来源。

**何时不该用**：阳性对照无法构造时——此时只能标注「未验证」，不能下否定结论。

**互斥组**：归因定位（P-03 / P-11 / P-07 / P-06），同组最多选 1
**来源**：[自撰]

### P-12 · 失败诊断飞轮有前提才建（源自 R07）

**主张**：高频重复链路的失败才值得转化为自动诊断闭环；一次性低频任务不建飞轮。

**怎么用**
1. 先确认执行频次与失败样本量。
2. 频次不足 → 不建，人工看即可。
3. 频次足够 → 建「诊断根因 → 草拟修复 + 新增检查项 → 过确认门 → 写入校验器」。

**改变了哪个决策**：原打算「给这个流程也建一套自动失败诊断」→ 改为「先数频次，低频就人工看」。

**什么证据会推翻**：若低频链路的失败后果极重（不可逆），则频次不是唯一前提。

**何时不该用**：一次性任务、失败样本量不足以归纳时。

**互斥组**：无
**来源**：[自撰]
