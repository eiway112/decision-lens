# 问题形态分类与透镜路由

> **S1 必读**，每次运行都加载本文件。本文件回答「这个问题属于哪一格」以及「这一格该看哪几个透镜」。

---

## 一、S0 准入门：这个问题该不该走本技能（4 问）

| 编号 | 判定问句 | 计分判据 |
|---|---|---|
| Q1 模糊 | 原始问题能否直接转成可执行任务？ | 不能直接转 → 得 1 分 |
| Q2 高杠杆 | 判断错了，返工成本 / 影响面多大？ | 落在 Meadows 阶梯 #1–#5 → 得 1 分 |
| Q3 多约束 | 是否存在 ≥2 个互相冲突的约束或目标？ | 有冲突 → 得 1 分 |
| Q4 长期 | 结论是否会被引用 >1 次？ | 会 → 得 1 分 |

- **≥3 分** → 走全链路，八要素全出
- **=2 分** → 走简版：只出要素 ①②③⑧，稿头写明「简版，得分 2」
- **≤1 分** → **明确拒绝并指明改用什么**（不许硬拒后什么都不给）

**Q2 不靠感觉**：挂 Meadows 12 级杠杆阶梯（由强到弱）——
①范式 ②目标 ③自组织 ④规则 ⑤信息流 ⑥激励 ⑦负反馈 ⑧正反馈 ⑨延迟 ⑩存量结构 ⑪缓冲 ⑫参数。
判据：这个判断落在 #1–#5 还是 #9–#12。落在低层即不得分。
来源：https://donellameadows.org/archives/leverage-points-places-to-intervene-in-a-system/

## 二、维度 A · 因果可知性（5 值）

| 值 | 判据 | 该域默认应对 |
|---|---|---|
| **clear** | 因果对所有人显然 | sense–categorize–respond（套既有最佳实践） |
| **complicated** | 因果需分析 / 专家可知 | sense–analyze–respond（套良好实践） |
| **complex** | 因果只能事后可见 | probe–sense–respond（先探针试） |
| **chaotic** | 系统层面无因果 | act–sense–respond（先止血） |
| **disorder** | 不知道属于哪一类 | **先分类，不要直接作答** |

> **disorder 是本技能的最高价值场景**：绝大多数「我拿不准」其实是 disorder，而默认做法是按 clear 处理。
> 命中 disorder → 强制先做分类，且**分类结论本身要作为要素②的一条隐含假设写出来**。

来源：Cynefin framework（Kurtz & Snowden 2003；Snowden & Boone 2007, HBR）
https://en.wikipedia.org/wiki/Cynefin_framework

## 三、维度 B · 决策类型（6 值）

`选型`（多方案挑一个）｜`取舍`（冲突目标之间让多少）｜`归因`（为什么会这样）｜`边界`（做到什么程度停）｜`时序`（先做什么后做什么）｜`是否做`（启动 / 撤销 / 继续）

## 四、维度 C · 辅助：可逆性 × 可机验性（2×2）

决定要素⑧的交接强度：**不可逆且可机验** → 交接给强制闸门；**可逆且不可机验** → 交接给信任 + 抽检。

## 六、路由算法（机械化，不靠拍脑袋）

```
候选集 = ROUTE[A][B]                       # 每格 2-3 个透镜 id
候选集 = 候选集 减去同族互斥组重复项         # 8 组，同组最多留 1
候选集 = 按「决策增量强度」降序排序
取 Top-3
for 每个候选:
    填要素④「改变了哪个决策」（必须含「原打算 X → 改为 Y」）
    填不出 → 撤下该透镜，回补下一名
最终保留 1-3 个
```

## 七、防无差别全量套用（最大失败模式）· 4 条机制

| 机制 | 做法 | 机检编号 |
|---|---|---|
| **M1 预算硬约束** | 选中透镜数 ∈ [1,3]。选 0 → FAIL（说明问题不该走本流程）；≥4 → FAIL | B3 |
| **M2 决策增量绑定** | 每个被选透镜必须填「改变了哪个决策」，且含转折标记 | B5 |
| **M3 同族互斥** | 8 个互斥组，同组最多 1 | B8 |
| **M4 反向闸门** | 必须写「没选哪 ≥2 个强透镜 + 为什么没选」 | B7 |

全量套用的本质是「每个透镜都能说上两句话，但没有一个真正改变决策」。
M1 卡数量、M2 卡质量、M3 卡冗余、M4 卡沉默——四条分别堵住四个逃逸口。

## 九、七条元判据（不参与路由，是透镜的准入过滤器）

| id | 名称 | 判据 |
|---|---|---|
| M1 | 判据先行 | 没有可机验判据的保证，不算保证。判据不可执行时须显式标注 |
| M2 | 角色分离 | 生成者不裁定，裁定者不生成 |
| M3 | 分层不对称 | 知识与行动、留痕与生效、编译与解释，各自用相反的纪律 |
| M4 | 衰减意识 | 先写失效判据，再写机制 |
| M5 | 事实回源 | 结论必须指回源事实，禁止中间产物自引用闭环 |
| M6 | 机制自证 | 管系统的机制自身必须先证明：抓得住违规、不误伤合法 |
| M7 | 分发三问 | 含绝对路径或身份事实→不分发；依赖特定语境→不分发；去语境后仍能改变他项目决策→可分发 |

> M7 是本技能开源脱敏的执行判据：每条透镜卡的来源与样例过 M7 才允许进公开仓。
